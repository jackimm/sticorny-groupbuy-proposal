## 고치는 순서 (한 번에 몰아서)

`main`에는 바로 저장할 수 없습니다. 고친 내용은 항상 **변경 요청(Pull request)**이 되고, 미리 보고 확인한 뒤에 사이트에 올라갑니다.

1. GitHub에 로그인해 이 저장소에서 `site` → `index.html`을 누릅니다.
2. 오른쪽 위 **연필 아이콘(Edit this file)**을 누릅니다.
3. 편집 칸을 한 번 누른 뒤 <kbd>Ctrl</kbd>+<kbd>F</kbd>로 바꿀 문구를 찾아 고칩니다.
4. 오른쪽 위 초록 **Commit changes...** 버튼을 누릅니다.
   - 메시지 칸에 무엇을 바꿨는지 적습니다. 예: `잘라쓰는 UV 공구가 3,900 → 3,500`
   - **Create a new branch for this commit and start a pull request**를 고른 채로 **Propose changes**를 누릅니다.
5. 다음 화면에서 **Create pull request**를 누릅니다.
6. 2~3분 뒤 그 페이지 아래에 Netlify가 **Deploy Preview** 링크를 답니다. 눌러서 고친 결과를 확인합니다. 미리보기는 실제 사이트에 영향이 없고 무료입니다.
7. 더 고칠 것이 있으면 아래 "같은 요청에 더 고치기"를 따라 같은 요청에 모읍니다.
8. 다 확인했으면 **Merge pull request** → **Confirm merge**를 누릅니다. 1~2분 뒤 실제 사이트가 바뀝니다.

### 같은 요청에 더 고치기

저장소 첫 화면 왼쪽 위 브랜치 선택(`main`이라고 적힌 곳)에서 방금 생긴 브랜치(예: `jackimm-patch-1`)를 고릅니다. 그 상태로 다른 파일을 고치고 **Commit directly to the ... branch**로 저장하면 같은 요청에 들어가고, 미리보기도 다시 만들어집니다.

## 사진 바꾸기

| 파일 (`site/images/`) | 자리 | 지금 크기 |
|---|---|---|
| `hero.webp` | 맨 위 대표 사진 | 1000×1000 |
| `prod-1-uv-cut.webp` | 잘라쓰는 UV 네임스티커 | 980×980 |
| `prod-2-uv-peel.webp` | 떼어쓰는 UV 네임스티커 | 980×653 |
| `prod-3-cloth-sticker.webp` | 의류용 네임스티커 | 980×980 |
| `prod-4-cloth-stamp.webp` | 의류용 네임스탬프 | 980×980 |

- `site/images` 폴더에서 **Add file → Upload files**로 **같은 이름의 .webp 파일**을 올리면 덮어씁니다. 저장할 때는 위 4번처럼 새 브랜치와 변경 요청으로 합니다.
- jpg·png를 쓰려면 파일을 올린 뒤 `index.html`에서 `images/hero.webp` 같은 이름도 함께 바꿉니다.
- 가로 1000px 안팎이 좋습니다. 사진이 크면 사이트가 느려지고 크레딧도 더 듭니다.
- 사이트 화면에 사진을 끌어다 놓으면 바뀐 것처럼 보이지만, 그 브라우저에서만 보이고 저장되지 않습니다.

## 건드리면 안 되는 곳

- `<` `>` 꺾쇠 안의 글자(태그)와 `class="..."` 같은 부분. 글자만 바꿉니다.
- `ACCESS_KEY`, `FORM_ENDPOINT` 줄. 문의 폼을 메일로 보내 주는 연결입니다.
- `index.html` 맨 아래 `tweaks-panel`, `tweaks-app` 부분. 화면 색을 정하는 프로그램입니다.

## 크레딧 (중요)

사이트는 Netlify 무료 요금제로 돌아갑니다. 한 달에 300크레딧이 있고, 이 계정의 다른 사이트와 같이 씁니다. **다 쓰면 그달 말까지 사이트가 멈춥니다.**

| 일 | 크레딧 |
|---|---|
| 변경 요청의 미리보기 | 0 |
| **Merge** (실제 사이트에 올리기) 1번 | 15 |
| 방문자가 받는 데이터 1GB (지금 사이트는 한 번 열 때 약 6.5MB) | 20 |
| 되돌리기 (Netlify에서 이전 배포로) | 0 |

자잘한 수정은 **한 변경 요청에 모아서 Merge는 한 번만** 하세요.

## 잘못 올렸을 때

- **가장 빠름 (Netlify 계정 필요):** Netlify의 Deploys 화면에서 바로 전 배포를 누르고 **Publish deploy**를 누릅니다. 크레딧이 들지 않습니다.
- **GitHub에서:** 문제의 변경 요청 페이지에서 **Revert**를 누르면 되돌리는 요청이 새로 만들어집니다. 그것을 Merge합니다(15크레딧).
- 두 사람이 같은 줄을 고치면 GitHub가 "conflict"라고 알려 줍니다. 혼자 풀지 말고 담당자에게 알리세요.
